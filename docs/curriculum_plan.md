# 單元學習課程規劃（單元 1～31）

目標：用敬語（해요體）有禮貌地跟陌生人溝通，範圍以 TOPIK I（1～2 級）為主。
決定者：使用者（出點子、把關、決定方向）；Claude 負責規劃、製作與驗證。

## 設計原則

1. 一個單元只教一個主要情境、一到兩個主要句型。
2. 單元句子只用敬語；每句標語氣（日常禮貌 해요體／尊敬說法 -세요）。半語只在「半語（額外學習）」。
3. 單字只用既有單字庫（1,089 個），不另外生一批新單字。
4. 單元測驗只考前面出現過的單字，錯誤選項也一樣。
5. 文法用文法庫裡的完整文法卡，一個文法點只放進一個單元。
6. -(으)ㅂ시다（一起…吧）對長輩、陌生人不夠禮貌，不放進單元，只留在基礎文法。
7. 職場版（합니다體）與對長輩的進階尊敬說法目前隱藏（`lib/data/course_options.dart`）；單元 9 之後不另做職場版。

## 驗證流程（每個單元）

1. 撰寫後跑 `python3 tool/validate_content.py`（自動錯誤偵測，見下方）。
2. 由沒看過撰寫過程的獨立審查員逐句複查韓文自然度、語氣與中文翻譯。
3. 修正後再跑一次偵測工具，必須 0 個錯誤。
4. 使用者電腦上跑 `flutter analyze`、`flutter test`（Claude 的環境無法安裝 Flutter）。

所有內容仍屬「待查核」：自動偵測與 AI 複查不等於母語者或官方查核。
